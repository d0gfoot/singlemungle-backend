# AI 스타일 시뮬레이션 구현 상태

AI 스타일 시뮬레이션의 현재 구현 상태와 배포 전 후속 작업을 기록합니다.

## 확정 구조

- Vertex AI Gemini 이미지 모델을 사용합니다.
- Google Places는 미용샵 탐색 정보에만 사용하며 외부 리뷰 사진을 자동 수집하지 않습니다.
- 참고 스타일은 전역 프리셋, AI 참고에 동의한 자체 리뷰 이미지, 사용자 직접 업로드 이미지, 추가 요청으로 구성합니다.
- 반려견 원본과 참고 이미지는 임시 디렉터리에 저장하고 작업 성공/실패 후 삭제합니다.
- 생성 결과만 영구 이미지 디렉터리에 저장하며 30일 후 정리합니다.
- 생성은 애플리케이션 내부 실행기를 통한 비동기 방식이고 상태는 `PENDING`, `COMPLETED`, `FAILED`입니다.

## 데이터 모델

- `grooming_style_presets`: 전역 프리셋 이름, 설명, 프롬프트, 제외 특성
- `reviews`: Google Place ID로 연결된 자체 미용샵 리뷰와 스타일명
- `review_images`: 리뷰 이미지 URL과 AI 참고 동의 여부
- `beauty_style_simulations`: 프리셋/리뷰 이미지 참조, 주요 입력 출처, 생성 상태와 결과 URL

`google_place_id`는 리뷰 이미지에서 추론할 수 있어 nullable입니다. `style_keyword`는 기존 응답 호환과 선택 스타일 표시를 위해 nullable로 유지합니다. 원본/참고 URL 컬럼은 비동기 작업 중 임시 파일 경로를 노출하지 않으며 신규 생성에서는 null입니다.

## 발표 데이터 준비

1. 팀 소유 또는 사용 허가를 받은 미용 결과 이미지를 `demo/review-images`에 둡니다.
2. 실제 DB의 사용자 ID와 Google Place ID에 맞게 로컬 데모 리뷰 데이터를 수정합니다.
3. PostgreSQL 컨테이너와 백엔드 마이그레이션을 실행합니다.
4. 로컬 데모 리뷰 시드 도구를 실행합니다.
5. 리뷰 이미지 ID를 Swagger에서 조회해 시뮬레이션에 전달합니다.
